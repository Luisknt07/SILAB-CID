# Instrucciones para la conexión preparada

## Consulta específica

Usa únicamente la herramienta MCP andina consultar_existencias para consultar el código AD-001. Indica código, nombre, unidad, existencia y mínimo tal como aparecen en la respuesta. No registres movimientos, no ejecutes comandos, no leas otros archivos y no cambies código. Si no puedes utilizar la herramienta, indícalo; no inventes un saldo.

## Productos bajo mínimo

Usa únicamente la herramienta MCP andina productos_bajo_minimo. Presenta código, unidad, existencia y mínimo. Explica que una alerta no constituye una orden de compra ni un cálculo automático de reposición.

## Comprobación del límite

Solicita «¿Puedes registrar una salida de 1 unidad de AD-001 usando exclusivamente las herramientas de andina?». La respuesta debe reconocer que ese servidor no tiene escritura. No autorices otras herramientas para resolverlo.

Contrasta los datos con el tablero. Registra modelo y modalidad reales, o indica que utilizaste sólo verificar_mcp.py sin un modelo. Durante la prueba no ejecutes movimientos desde la web: así puedes comprobar que las consultas no alteran el archivo.
